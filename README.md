# 📖 Overview

**Restaurio Pro** is a fully functional front-end Restaurant Point of Sale (POS) application developed using **HTML, CSS, and Vanilla JavaScript**.

The project simulates a real-world restaurant cashier system capable of handling customer orders, billing, kitchen tickets, receipt printing, menu management, daily sales tracking, and much more — all without requiring any external frameworks.

The application is designed with a modern industrial UI inspired by restaurant kitchen terminals while remaining lightweight and easy to customize.
